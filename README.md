# Ticket Booking App - Backend

## Hướng dẫn cài đặt và chạy dự án

clone:
```bash
git clone ⁦https://github.com/minq3010/Ticket-Booking-App-Backend.git⁩
```
vào nhánh docker: 
```bash
git checkout docker
```

mở docker
đảm bảo ở đúng folder
ở terminal:
   1. ```make start``` (chạy chương trình)
   2. ```make stop``` (dừng chương trình)

sửa gì thì tạo nhánh mới:
```bash
git checkout -b <tên nhánh của mày>
```
